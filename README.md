# Profile and Contact Page

## Project Description
This project is a single-page personal profile and contact website built to demonstrate HTML5 document structure, semantic HTML, and accessible forms.

## Features
- Semantic HTML structure using header, navigation, main, article, section, and footer.
- Personal profile with a profile picture and alternative text.
- About Me section with lists of interests and goals.
- Accessible contact form with connected labels.
- Contact reason dropdown menu.
- Required fields with built-in HTML form validation.
- Newsletter subscription checkbox.
- Responsive styling using CSS.

## Technologies Used
- HTML5
- CSS3

## How to View the Project
Open `index.html` in a web browser, or visit the live website below after GitHub Pages has finished publishing it.
